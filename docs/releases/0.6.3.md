# vault 0.6.3

- 修复 MCP 客户端（Claude Code 等）丢弃批量 CRUD 工具的问题：这 5 个工具的输入 schema 不再使用根级 `oneOf`，改为只声明 `items` 批量形态。
- 恢复可见的工具：`search_entries`、`get_entries`、`create_entries`、`update_entries`、`delete_entries`，MCP 工具总数恢复为 12 个。
- 运行时继续兼容旧的单条调用（如 `{id}`、`{query}`），现有脚本和调用方无需修改；批量调用返回 `{"results": [...]}`。
- 新增 schema 回归测试，防止根级 `oneOf`/`anyOf`/`allOf` 再次导致工具被丢弃。
- 版本号集中到 `package.json` 与根 `Cargo.toml` 的 `[workspace.package]`，各成员 crate 使用 workspace 继承，`tauri.conf.json` 直接读取 `package.json`。
- 内部 Cargo/npm 包名统一为 `vault`，构建产物改为 `vault.exe`；安装目录、数据格式、本地缓存和更新标识保持不变。

## 下载

- `vault-0.6.3-setup.exe`：安装版，默认 `D:\vault`，可选择目录。卸载保留 data。
- `latest.json`：客户端自动更新所用签名信息，无需手动打开。

Windows 10/11 x64，使用系统 WebView2 Runtime。支持当前 schema 4 密码库。
