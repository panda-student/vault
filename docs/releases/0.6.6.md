# vault 0.6.6

- 修复 MCP 无法连接：部分电脑的安全软件（如 360）不允许在 `Vault` 联接目录下创建新子目录，导致 MCP 桥接启动即失败并被反复拉起。协调文件现在直接使用联接指向的真实目录。
- 升级后可手动删除 `%LOCALAPPDATA%\LocalPasswordManager\updates` 下旧版残留的登记目录。

## 下载

- `vault-0.6.6-setup.exe`：安装版，默认 `D:\vault`，可选择目录。卸载保留 data。
- `latest.json`：客户端自动更新所用签名信息，无需手动打开。

Windows 10/11 x64，使用系统 WebView2 Runtime。支持当前 schema 4 密码库。
