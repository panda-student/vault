# vault 0.6.4

- 彻底统一内部命名：Cargo 包名、npm 包名、构建产物、Tauri 应用标识、更新协调目录、开机启动注册表值和签名密钥目录全部改为 `vault`。
- 兼容旧版本：首次启动会在旧目录存在时为 `LocalAppData\LocalPasswordManager` 创建 `Vault` junction，旧版 MCP 连接仍可被原地升级暂停和恢复。
- 开机启动项自动从 `LocalPasswordManager.Portable` 迁移到 `Vault`，并清理旧值。
- 旧密码库继续读取并用旧标记写入，回退到 0.6.3 仍可读取升级后新增的条目；0.6.4 新建的密码库使用 `vault` 标记，回退后只能打开空库。
- 更新检查、下载、安装和回退流程不受影响。

## 下载

- `vault-0.6.4-setup.exe`：安装版，默认 `D:\vault`，可选择目录。卸载保留 data。
- `latest.json`：客户端自动更新所用签名信息，无需手动打开。

Windows 10/11 x64，使用系统 WebView2 Runtime。支持当前 schema 4 密码库。
