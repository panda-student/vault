# vault 0.6.8

- 安全更新：升级 MCP 组件和本地数据库组件，修复了以下已知问题：恶意或异常的 MCP 服务端可能让程序耗尽内存；OAuth 客户端的地址检查不完整；工具定义缓存没有上限。
- GitHub 同步改为直接填写仓库地址，例如 `https://github.com/owner/repo`，不再分别填写所有者、仓库名和分支。
- 其余改动是开发和发布流程，不影响使用。

## 下载

- `vault-0.6.8-setup.exe`：安装版，默认 `D:\vault`，可选择目录。卸载保留 data。
- `latest.json`：客户端自动更新所用签名信息，无需手动打开。

Windows 10/11 x64，使用系统 WebView2 Runtime。支持当前 schema 4 密码库。
