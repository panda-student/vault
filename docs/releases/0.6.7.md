# vault 0.6.7

- 新增远程同步：可把密码库加密后同步到本地/网盘文件夹、WebDAV 或 GitHub 私有仓库，多台电脑自动合并。同步口令只由你在桌面输入，用 Windows 用户身份保存；远端只存加密文件，且只读写自己的同步文件。
- 两边有差异时弹窗选择：本地覆盖云端、云端覆盖本地或双向同步。从云端恢复前会先校验口令，不对则不写入任何数据。
- Token 和密码只引用密码库里的凭据，AI 看不到明文；GitHub 仅允许私有仓库。
- MCP 新增 `get_settings`、`update_settings` 和 `sync_now`：AI 可以查看全部设置、修改非权限类设置并立即同步；更换同步目标需要在桌面确认，权限规则和冲突处理仍只能在桌面操作。
- `search_entries` 与其他批量工具一致，改用 `items` 列表。
- 修复部分电脑上 MCP 无法连接的问题：安全软件不允许在 `Vault` 联接目录下创建子目录，协调文件现在直接使用联接指向的真实目录。

## 下载

- `vault-0.6.7-setup.exe`：安装版，默认 `D:\vault`，可选择目录。卸载保留 data。
- `latest.json`：客户端自动更新所用签名信息，无需手动打开。

Windows 10/11 x64，使用系统 WebView2 Runtime。支持当前 schema 4 密码库。
