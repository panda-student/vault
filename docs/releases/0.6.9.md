# vault 0.6.9

- 新增统一输入出口 `write_credential` 的 `target.type=auto`：只要说清在哪填（网页、正在等密码的控制台程序、桌面窗口的输入框），vault 会自己选输入方式，不行就换下一种，结果里写明实际用了哪种、跳过了哪些。
- vault 启动的程序（`target.type=command`）中，git、ssh 等弹出的密码提示由 vault 自动代答。只有提示里的主机属于该条目时才会回答，其他主机一律拒绝。
- 只给真正在等密码的控制台输入。没在等密码的控制台、Windows Terminal 这类终端窗口都不会输入，并返回原因。
- 密码和 token 依旧不会出现在返回给 AI 的任何结果里。

## 下载

- `vault-0.6.9-setup.exe`：安装版，默认 `D:\vault`，可选择目录。卸载保留 data。
- `latest.json`：客户端自动更新所用签名信息，无需手动打开。

Windows 10/11 x64，使用系统 WebView2 Runtime。支持当前 schema 4 密码库。
