# vault 0.6.2

- 应用内更新改为下载并静默运行签名安装包，安装器负责关闭旧程序、替换文件、恢复 MCP 连接并按原数据目录重启。
- 更新只使用安装包，不再提供便携 ZIP。
- 发布流程简化：合并到 main 后自动发布正式版，不再发布预发行版。

## 下载

- `vault-0.6.2-setup.exe`：安装版，默认 `D:\vault`，可选择目录。卸载保留 data。
- `latest.json`：客户端自动更新所用签名信息，无需手动打开。

Windows 10/11 x64，使用系统 WebView2 Runtime。支持当前 schema 4 密码库。
