# vault 0.6.1

- “软件更新”移到左侧一级导航，可以直接检查、下载并重启更新。
- 底部的新版本提示直接打开软件更新页，设置页保留启动、托盘和本地密码库选项。
- 正式发布安装包、便携 ZIP 和 Ed25519 签名的更新信息，0.6.0 客户端可检测到此版本。
- 桌面与 MCP 共用 Rust 核心；保留更新等待在途操作、失败回退及 MCP 连接恢复。
- 本地与 CI 共用完整打包和安装验收流程。

## 下载

- `vault-0.6.1-setup.exe`：安装版，默认 `D:\vault`，可选择目录。
- `vault-0.6.1.zip`：便携版，解压启动 `vault.exe`。
- `latest.json`：客户端自动更新所用签名信息，无需手动打开。

Windows 10/11 x64，使用系统 WebView2 Runtime。支持当前 schema 4 密码库；旧格式不在本次自动转换范围。密码库仍绑定原 Windows 用户和电脑。
